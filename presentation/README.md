# Презентация «Ведома»

Веб-версия презентации для онлайн-этапа: 21 слайд 1920×1080, один блок `<section>` — один слайд, без анимаций.
В деплой не входит (исключена в `.dockerignore` и `deploy.bat`).

## Перед экспортом

1. Откройте `private.js` и впишите служебные значения для слайда 1: ссылку на репозиторий, пароль панели,
   `STAFF_CODE`, токен бота и ключ Polza.AI. Файл **не попадает в git** — секреты остаются только у вас.
   Пустые поля на слайде подсвечены красным.
2. Откройте `index.html` в Chrome или Edge.

## Экспорт в PDF

`Ctrl+P` → Принтер: **Сохранить как PDF** → Поля: **Нет** → включить **Фоновая графика** → Сохранить.
Размер страницы задаётся самой презентацией (1920×1080), 21 страница.

## Файлы

- `index.html` — слайды; `deck.css` — оформление (палитра продукта, шрифты Unbounded и Golos Text, OFL);
- `deck.js` — подставляет значения из `private.js` и масштабирует слайды под окно (на печать не влияет);
- `assets/img` — скриншоты работающего MVP (данные тестовые), `assets/fonts` — шрифты и лицензия.
